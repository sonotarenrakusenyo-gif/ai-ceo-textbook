# AI・テック帝国：戦国時代のCEO教科書

現代のAI業界を動かす7人のCEOと、4つの勢力が織りなす「戦国時代」の全体像を学ぶための教科書です。

**Web版（スマホ対応）：** Next.js で構築。Vercel にデプロイして携帯から閲覧できます。

## ローカル開発

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

---

## この教科書で学べること

1. **主要7社の正式名称と現CEO** — ニュースで名前を聞いても、どの会社の誰かがすぐわかる
2. **各CEOの経歴と人物像** — なぜその人がトップに立つのか、背景まで理解できる
3. **業界の勢力図** — Microsoft×OpenAI、反OpenAI派、マスク陣営、NVIDIAという4層構造

## 推奨する読み方

```
初めて読む人  →  第1部 → 第3部 → 第2部（興味のあるCEOから）
CEOを深く知りたい  →  第2部を中心に、第3部で文脈を確認

```
